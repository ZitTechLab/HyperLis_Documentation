## 2. Tổng quan

HyperLis hỗ trợ đa ngôn ngữ giao diện giúp người dùng thuận tiện theo dõi: **Tiếng Việt (vi-VN)** và **English (en-US)**.

## 3. Hướng dẫn chuyển ngôn ngữ

<Steps>
1. Mở HyperLis, truy cập menu cài đặt, mục **Choose a language / Chọn ngôn ngữ**.
2. Chọn ngôn ngữ mong muốn trong menu thả xuống:
   * **Tiếng Việt** (Giao diện Tiếng Việt)
   * **English** (Giao diện Tiếng Anh)
3. Ứng dụng sẽ tự động làm mới giao diện với ngôn ngữ đã chọn.
</Steps>

<Aside type="note">
Tài liệu hướng dẫn kỹ thuật này luôn sử dụng tiếng Việt để thuận tiện cho việc tra cứu.
</Aside>
