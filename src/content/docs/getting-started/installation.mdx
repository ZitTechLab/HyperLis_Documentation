## 2. Yêu cầu hệ thống

* **Hệ điều hành**: Windows 10 (64-bit) hoặc Windows 11 (64-bit).
* **Quyền thực thi**: Quyền Quản trị viên (Administrator).
* **Kết nối Internet**: Cần thiết khi tải ứng dụng và cập nhật.

## 3. Hướng dẫn cài đặt

<Steps>
1. Tải bản dựng HyperLis mới nhất từ Facebook của [Zịt's Tech Lab](https://www.facebook.com/ZitTechLab).
2. Mở tệp cài đặt có tên `HyperLis_Setup_v1.x.x.exe`.
3. Nếu có hộp thoại UAC (User Account Control) xuất hiện, chọn **Yes** để cấp quyền Quản trị viên cho phần mềm.
4. Chọn **Next** để tiếp tục cài đặt.
5. Chọn **Next** để tiếp tục với đường dẫn cài đặt mặc định `C:\Program Files (x86)\HyperLis\`.
6. Chọn **Create a desktop shortcut** nếu muốn tạo biểu tượng ở desktop, chọn **Next** để tiếp tục.
7. Chọn **Install** để bắt đầu cài đặt.
8. Chờ cho đến khi quá trình cài đặt hoàn tất, sau đó nhấn **Finish** để đóng trình cài đặt.
</Steps>
